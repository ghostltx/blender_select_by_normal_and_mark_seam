# Xelias的快捷按键

Blender 插件 v1.5。在 3D 视图 N 面板的 **工具 → Xelias** 里，提供网格处理、文件清理、相机标记和相机反射布光。

- 文件：`select_by_normal_and_mark_seam.py`
- 兼容：Blender 2.80 及以上
- 位置：View3D > 侧边栏（N）> **工具** > **Xelias**

## 安装

1. 打开 Blender，进入 **编辑（Edit）> 偏好设置（Preferences）**。
2. 打开 **插件（Add-ons）**。
3. 点击 **安装（Install...）**，选择本仓库的 `select_by_normal_and_mark_seam.py`。
4. 勾选启用 **Xelias的快捷按键**。
5. 在 3D 视图按 `N` 打开侧边栏，切到 **工具**，即可看到 **Xelias** 面板。

已安装过旧版时，用同一文件重新安装并启用即可。面板里的操作都支持撤销。

## 使用

### 选择并标记

**选择相同法线面并标记缝合线**

在编辑模式里，按法线相似度选中同类面，并把这块区域的轮廓边标成缝合线。

1. 选中网格，进入编辑模式。
2. 选中一个面。插件以第一个选中面的法线为基准。
3. 按需要调整 **法线角度阈值**（默认 5°，范围 0–180°）。
4. 点击 **选择相同法线面并标记缝合线**。

插件会切到面选择、选中夹角在阈值内的面、把选区转成轮廓边并标记缝合线，然后回到面选择。没选面时会提示。

### 网格数据

**独立化选中网格**

给选中对象里「多用户」的 Mesh 数据各复制一份，变成单用户数据，避免应用修改器时出现「无法应用一个多用户」。已经是单用户的网格不会再复制。

在物体模式选中一个或多个网格后点击。

### 自定义属性

**添加 color 属性**

给当前选中的对象添加名为 `color` 的自定义属性：Float Array、子类型为颜色（Linear Color）、长度 3，默认白色 `(1, 1, 1)`，范围 0–1。请先选中对象或实例。

### 顶点组

**清除所选顶点组**

清除当前选中网格上的全部顶点组。不会删除模型，也不会去掉骨骼修改器。至少选中一个网格后可用。

### 文件

**清理丢失资源**

删除找不到文件、且没有打包的贴图（来源为文件、序列或分块）。用来解决保存时「无法打包文件」的报错。不改变自动打包设置。没有丢失贴图时会提示。

### 相机标记

**按相机创建标记**

收集当前场景里的全部相机，按名称自然排序（例如 1、2、10），然后：

- 清掉已有的时间轴标记
- 把帧范围设为 1 到相机数量
- 为每台相机在对应帧建一个同名标记，并绑定这台相机

场景里没有相机时，不会改帧范围，也不会动已有标记。

### 相机反射灯光

按场景相机（没有场景相机时，用当前 3D 视口的观察位置）和物体表面的真实法线，把灯光摆到反射方向上，让高光落在指定位置。反射方向会挡住镜头时，自动向侧前方偏约 35°，并略微抬高，避免灯挡在画面正中。

定位使用表面真实法线，不会用「朝向相机」的假法线凑结果。

**相机反射定位灯光**

在 3D 视口里使用。当前没有选中灯光时，会新建一盏名为「反射面光」的面光（尺寸 1，能量 100）。

| 操作 | 作用 |
| --- | --- |
| 鼠标在物体表面移动 | 按该点的相机反射角实时摆灯，灯光朝向命中点 |
| 滚轮 | 调整灯到表面的距离（按住 Shift 调得更细） |
| `[` / `]` | 缩小 / 放大面光尺寸（只对面光生效） |
| 左键、回车或空格 | 确认放置 |
| 右键或 Esc | 取消并还原：新建的灯会删掉；原来的灯会恢复位置、旋转和尺寸 |
| 中键或触控板 | 照常旋转、平移、缩放视图 |

视口顶栏会显示当前距离、面光尺寸，以及是否已经偏开镜头。确认前请先把鼠标指到物体表面上。

**一键对齐反射角**

把已经选中的灯光，按场景相机和真实表面法线对齐到反射角，并尽量保留灯到命中点的当前距离。

- 同时选中灯光和目标网格：从相机朝该网格的包围盒中心打射线，取真实命中点和法线。
- 只选中灯光：从相机朝 **3D 游标** 打射线，命中场景里的物体表面。
- 正面直射、反射方向会挡镜头时，自动侧偏约 35°。

没打到表面时会提示：请同时选中目标网格，或把 3D 游标放到物体表面上。需要先设置场景相机，或在 3D 视口中操作。

## 更新日志 / v1.5 升级说明

仓库里的上一版是 v1.0，只有「选择相同法线面并标记缝合线」，面板名称是「法线选择工具」。v1.5 在保留这项功能的同时，把插件扩成 **Xelias的快捷按键**。

- 插件更名为 **Xelias的快捷按键**。N 面板改为 **工具 → Xelias**，并按功能分组。
- 原有的按法线选面并标记缝合线仍然可用，阈值默认仍是 5°。
- 新增 **添加 color 属性**：给选中对象写入长度为 3 的 `color` 颜色自定义属性。
- 新增 **清除所选顶点组**：只清顶点组，不删模型和骨骼修改器。
- 新增 **独立化选中网格**：把多用户 Mesh 复制成单用户，方便应用修改器。
- 新增 **清理丢失资源**：去掉找不到文件且未打包的贴图，避免保存时打包失败。
- 新增 **按相机创建标记**：按相机名自然排序，重建时间轴标记和帧范围。
- 新增 **相机反射灯光**：
  - **相机反射定位灯光**：鼠标在表面上定位高光；滚轮调距离；`[` / `]` 调面光尺寸；右键或 Esc 取消并还原。
  - **一键对齐反射角**：按真实表面法线自动对齐。只选灯时，会从相机经 3D 游标向物体表面打射线。正面直射时自动侧偏约 35°，避免挡住镜头。
